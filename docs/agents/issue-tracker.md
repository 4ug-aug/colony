# Issue tracker: Local Markdown

Issues and PRDs for this repo live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- PRD: `.scratch/<feature-slug>/PRD.md`
- Implementation issues: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Triage state: a `Status:` line near the top of each file
- Comments: append under `## Comments`

Publishing to the issue tracker means creating the corresponding local file.
